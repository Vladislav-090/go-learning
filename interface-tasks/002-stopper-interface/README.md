# Task 002 - Stopper Interface

## Goal

Create a Stopper interface and use it to stop different services with the same function.

## Concepts

- Interfaces
- Methods
- Pointer Receiver
- Common Behavior
- Implicit Implementation

## What I Learned

- An interface describes behavior through method names.
- Different structs can satisfy the same interface if they have the required method.
- A function can work with an interface instead of a concrete struct.
- Go interfaces are implemented implicitly.
