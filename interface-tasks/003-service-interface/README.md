# Task 003 - Service Interface

## Goal

Create a Service interface with Start and Stop methods and use it to manage different services.

## Concepts

- Interfaces
- Multiple Methods
- Methods
- Pointer Receiver
- Implicit Implementation
- Polymorphism

## What I Learned

- An interface can require more than one method.
- A struct satisfies an interface only if it has all required methods.
- Different structs can be used through the same interface.
- Functions can work with behavior instead of concrete types.
