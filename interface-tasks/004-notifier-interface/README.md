Create a Notifier interface and use it to send alerts through different notification services.

## Concepts

- Methods

## What I Learned

- Different structs can satisfy the same interface.
- Functions can work with interfaces instead of concrete types.
- New implementations can be added without changing existing code.
- Go interfaces are implemented implicitly.
