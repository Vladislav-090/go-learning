# Task 005 - Payment Processor Interface

## Goal

Create a PaymentProcessor interface and process payments using different payment systems.

## Concepts

- Interfaces
- Methods
- Polymorphism
- Implicit Implementation

## What I Learned

- Different payment systems can implement the same interface.
- One function can work with multiple implementations.
- New implementations can be added without modifying existing code.
- Interfaces describe behavior, not data.
