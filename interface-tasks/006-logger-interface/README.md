# Task 006 - Logger Interface

## Goal

Create a Logger interface and use it to write logs through different logging services.

## Concepts

- Interfaces
- Methods
- Polymorphism
- Implicit Implementation
- Common Behavior

## What I Learned

- Different loggers can implement the same interface.
- One function can work with multiple logging implementations.
- New loggers can be added without changing the existing function.
- Interfaces describe behavior, not concrete types.
