# Task 008 - Balance Provider Interface

## Goal

Create a BalanceProvider interface and use it to print balances from different wallet types.

## Concepts

- Interfaces
- Multiple Methods
- Return Values
- Polymorphism
- Blockchain Wallets

## What I Learned

- An interface can require multiple methods.
- Different wallet types can satisfy the same interface.
- A function can work with different blockchain wallets through one common interface.
- Methods can return values from struct fields.
