# Task 010 - Blockchain Client Interface

## Goal

Create a BlockchainClient interface and use it to get blockchain network information through different clients.

## Concepts

- Interfaces
- Multiple Methods
- Return Values
- Polymorphism
- Blockchain Clients
- Function Abstraction

## What I Learned

- Different blockchain clients can satisfy the same interface.
- Methods can return data without printing it directly.
- A function can work with different blockchain networks through one common interface.
- Separating data retrieval from output makes code cleaner and more flexible.
