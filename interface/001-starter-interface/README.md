# Task 001 - Starter Interface

## Goal

Create a Starter interface and use it to run different services with the same function.

## Concepts

- Interfaces
- Methods
- Pointer Receiver
- Polymorphism
- Common Behavior

## What I Learned

- An interface describes behavior through methods.
- Different structs can satisfy the same interface.
- Go interfaces are implemented implicitly.
- A function can accept an interface instead of a concrete struct.
