# Task 007 - Storage Interface

Create a Storage interface and implement different storage types.

## Concepts

- Interfaces
- Multiple Methods
- Data Storage

## What I Learned

- An interface can contain multiple methods.
- Different storage implementations can satisfy the same interface.
- Functions can work with any type that implements the required methods.
- Data can be saved and loaded through a common interface.
