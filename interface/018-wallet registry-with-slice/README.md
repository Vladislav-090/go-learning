# Task 018 - Wallet Registry With Slice

## Goal

Create a wallet registry that stores wallet names in a slice and prevents duplicate wallets.

## Concepts

- Interfaces
- Structs
- Methods
- Slices
- append
- range
- len
- Duplicate Check
- Deleting from slice

## What I Learned

- A slice can store a list of wallets.
- `append` adds a new wallet to the slice.
- `range` can be used to search for existing wallets.
- A duplicate check prevents adding the same wallet twice.
- `len` returns the current number of wallets.
- An item can be removed from a slice using its index.
