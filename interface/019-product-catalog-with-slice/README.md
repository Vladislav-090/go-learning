# Task 019 - Product Catalog With Slice

## Goal

Create a product catalog that stores products in a slice and works through an interface.

## Concepts

- Interfaces
- Structs
- Methods
- Slices
- append
- range
- len
- Duplicate Check
- Update Item In Slice
- Delete Item From Slice

## What I Learned

- A slice can store a list of products.
- `append` adds a new product to the slice.
- `range` can be used to search for existing products.
- Duplicate checks prevent adding the same product twice.
- A product can be updated by changing the value at a specific index.
- A product can be deleted by combining parts of a slice.
- An interface can describe catalog behavior.
