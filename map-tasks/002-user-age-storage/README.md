# Task 002 - User Age Storage With Map

## Goal

Create a user age storage that stores user ages using a map.

## Concepts

- Interfaces
- Structs
- Methods
- Maps
- map[string]int
- Add value by key
- Delete value by key
- Get value by key
- range
- len

## What I Learned

- A map stores data as key-value pairs.
- A username can be used as a key.
- Age can be used as a value.
- A value can be added or updated by key.
- `delete` removes a key from a map.
- `range` can be used to print map data in a custom format.
- `len` returns the number of keys in a map.
