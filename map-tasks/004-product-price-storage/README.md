# Task 004 - Product Price Storage With Map

## Goal

Create a product price storage that stores product prices using a map.

## Concepts

- Interfaces
- Structs
- Methods
- Maps
- map[string]int
- Add value by key
- Delete value by key
- Get value by key
- Update value by key
- Duplicate Check
- range
- len

## What I Learned

- A map can store product name as a key and price as a value.
- A value can be added by key.
- Existing keys can be checked before adding new data.
- A value can be updated directly by key.
- `delete` removes a product by key.
- `range` can be used to print all products and prices.
- `len` returns the number of products in the map.
