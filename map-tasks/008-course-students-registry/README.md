# Task 008 - Course Students Registry With Map And Slice

## Goal

Create a course students registry that stores multiple students for each course.

## Concepts

- Interfaces
- Structs
- Methods
- Maps
- Slices
- map[string][]string
- append
- range
- len
- Delete item from slice
- Duplicate Check

## What I Learned

- A map can store a slice as a value.
- One course can have multiple students.
- A course can be created automatically if the key does not exist.
- A student can be added to a course.
- Duplicate students can be prevented.
- A student can be deleted from a slice inside a map.
- `range` can be used to iterate through courses and students.
- `len` returns the number of courses.
