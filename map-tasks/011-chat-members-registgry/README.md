# Task 011 - Chat Members Registry With Map And Slice

## Goal

Create a chat members registry that stores multiple members for each chat.

## Concepts

- Interfaces
- Structs
- Methods
- Maps
- Slices
- map[string][]string
- append
- range
- len
- Delete item from slice
- Duplicate Check

## What I Learned

- A map can store a slice as a value.
- One chat can have multiple members.
- A chat can be created automatically if it does not exist.
- A member can be added to a chat.
- Duplicate members can be prevented.
- A member can be deleted from a slice inside a map.
- `range` can be used to iterate through chats and members.
- `len` returns the number of chats.
