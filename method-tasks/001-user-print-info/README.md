# Task 001 - User Print Info

## Goal

Create a method for the User struct that prints user information.

## Concepts

- Structs
- Methods
- Value Receiver
- Function vs Method

## What I Learned

- A method is a function that belongs to a specific type.
- A value receiver is enough when the method only reads data.
- Methods make code more readable by connecting behavior with data.
