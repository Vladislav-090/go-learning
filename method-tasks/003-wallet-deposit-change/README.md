# Task 003 - Wallet Deposit

## Goal

Create a Wallet struct and add a method that increases the wallet balance.

## Concepts

- Structs
- Methods
- Pointer Receiver
- Updating Struct Fields

## What I Learned

- A method can change struct fields if it uses a pointer receiver.
- Pointer receivers are used when we need to modify the original struct.
- Methods help keep logic connected to the data it works with.
