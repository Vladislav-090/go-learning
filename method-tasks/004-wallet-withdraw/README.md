# Task 004 - Wallet Withdraw

## Goal

Create a Wallet struct and add a method that withdraws money from the wallet balance.

## Concepts

- Structs
- Methods
- Pointer Receiver
- Conditional Statements
- Balance Validation

## What I Learned

- A method can modify struct fields using a pointer receiver.
- Conditions can be used before changing data.
- Pointer receivers are useful when the method needs to update the original struct.
