# Task 006 - Bank Account Basic

## Goal

Create a bank account struct with methods for depositing and withdrawing money.

## Concepts

- Structs
- Methods
- Pointer Receiver
- Balance Updates
- Validation

## What I Learned

- One struct can have multiple methods.
- Pointer receivers allow methods to modify the original struct.
- Before changing balance, the method should check if the operation is valid.
