# Task 008 - Library Book

## Goal

Create a Book struct with methods for borrowing, returning, and printing book information.

## Concepts

- Structs
- Methods
- Pointer Receiver
- Boolean Fields
- State Management

## What I Learned

- Methods can change the state of a struct.
- Boolean fields can represent object status.
- Pointer receivers are used when a method modifies the original struct.
- One struct can have multiple methods that work with the same state.
