# Task 011 - Door Lock

## Goal

Create a Door struct with methods for opening, closing, locking, unlocking, and displaying door information.

## Concepts

- Structs
- Methods
- Pointer Receiver
- Boolean Fields
- State Management
- Early Return

## What I Learned

- One object can have multiple states at the same time.
- Methods can validate state before performing an action.
- `return` helps stop execution when an action is not allowed.
- Boolean fields are useful for tracking object status.
- Pointer receivers are used when a method modifies struct fields.
