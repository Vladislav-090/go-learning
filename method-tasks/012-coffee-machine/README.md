# Task 012 - Coffee Machine

## Goal

Create a CoffeeMachine struct with methods for turning on, turning off, adding water, making coffee, and displaying machine information.

## Concepts

- Structs
- Methods
- Pointer Receiver
- State Management
- Early Return
- Value Limitation

## What I Learned

- Methods can depend on the current state of an object.
- One method may require another action to be performed first.
- Early return helps prevent invalid operations.
- Struct fields can be used to model real-world objects and their behavior.
