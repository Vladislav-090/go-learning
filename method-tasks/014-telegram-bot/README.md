# Task 014 - Telegram Bot

## Goal

Create a TelegramBot struct with methods for starting, stopping, sending messages, and displaying bot information.

## Concepts

- Structs
- Methods
- Pointer Receiver
- Boolean Fields
- State Management
- Early Return

## What I Learned

- Methods can control the state of an object.
- A bot can send messages only when it is running.
- Early return helps prevent invalid actions.
- Pointer receivers are used when methods modify struct fields.
