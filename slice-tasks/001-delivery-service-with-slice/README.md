# Task 015 - Delivery Service With Slice

## Goal

Create a delivery service that stores real orders in a slice instead of using only a counter.

## Concepts

- Interfaces
- Structs
- Methods
- Slices
- append
- range
- len
- Deleting from slice

## What I Learned

- A slice can store a list of real values.
- `append` adds a new item to a slice.
- `range` can be used to loop through a slice.
- `len` returns the number of items in a slice.
- An item can be deleted from a slice by combining the part before and after the item.
- An interface can include methods for working with a collection.
