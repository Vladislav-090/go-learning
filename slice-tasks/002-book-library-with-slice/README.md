# Task 016 - Book Library With Slice

## Goal

Create a book library that stores books in a slice and works through an interface.

## Concepts

- Interfaces
- Structs
- Methods
- Slices
- append
- range
- len
- Deleting from slice

## What I Learned

- A slice can store a list of real values.
- `append` adds a new book to the slice.
- `range` is used to loop through all books.
- `len` returns the number of books in the slice.
- An item can be deleted from a slice by combining elements before and after it.
- An interface can describe behavior for working with a collection.
